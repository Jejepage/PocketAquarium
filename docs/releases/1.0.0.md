PocketAquarium 1.0.0 veröffentlicht eine direkt nutzbare, ruhige Aquariumszene mit unterschiedlich schwimmenden Fischen, Umgebungsbewegung, Touch-/Mausgesten für Neugier, Ausweichen und zusätzliche Fische sowie einer sichtbaren Fütterungsaktion.
